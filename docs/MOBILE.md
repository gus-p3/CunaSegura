# 📱 Módulo Móvil (Mobile App)

La aplicación principal de teléfono está diseñada para ser la herramienta que el vecino llevará siempre consigo. Actúa como el concentrador (Hub Central) del ecosistema.

## Características Principales
- **Reporte Rápido**: Cuenta con botones de Pánico/SOS para emitir alertas inmediatas a toda la red.
- **Geolocalización en Tiempo Real**: Visualización en mapas interactivos para localizar el origen de la alerta y coordinar la ayuda de manera efectiva.
- **Red Vecinal**: Gestión de contactos y redes de vecinos, en donde se asignan roles y permisos.
- **Modo Oscuro Integrado**: Tematización responsiva usando Material Design 3 en tonos azul medianoche (`#0F1416` y `#85D1E8`).
- **Vinculación con Relojes**: Conexión local vía Bluetooth Low Energy (BLE) para configurar las acciones físicas del smartwatch (Wear OS).

## Ejecución
Para compilar y ejecutar este módulo desde Android Studio:
1. En la barra superior, selecciona la configuración **`app`**.
2. Selecciona un dispositivo Android físico o emulador (API 30+).
3. Presiona **▶ Run**.
